# Paisaje de Refugio Kywai

`coastal-sunset.png` es un paisaje distante generado con la herramienta imagegen para este tema. La cúpula, los muebles, las plantas, los compañeros y las luces se dibujan en Three.js; la imagen no muestra una habitación ya construida. El shader anima agua y nubes, y se detiene con Reducir efectos. Es un panorama escénico, sin correspondencia geográfica exacta en 360 grados.

El recurso y la implementación proceden del prototipo de Refugio Kywai incorporado con autorización del usuario.
