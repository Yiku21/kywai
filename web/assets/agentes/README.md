# Marcas oficiales de agentes

Copias sin modificar de iconos publicados por los proveedores. Las fuentes exactas, páginas oficiales e identificadores están en `web/agentes-marcas.json`. Cada marca pertenece a su titular; su presencia identifica una integración y no implica patrocinio. El símbolo Copilot procede de Primer Octicons (MIT).

El catálogo se valida al compilar: cada agente, incluidos LM Studio y Ollama, debe tener su marca. No se sustituyen por avatares de kywai.
